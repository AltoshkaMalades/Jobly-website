## 🔧 Technical Implementation

### URL Structure
```
/                           # Home with Premium section
/pricing/                   # Full pricing page
/payments/paypal/           # Payment form
/payments/success/          # Success confirmation
/payments/error/            # Error handling
```

### Template Inheritance
```
base.html
├── pricing.html            # Pricing page
├── profile.html            # With upgrade section
├── index.html              # With premium section
└── course_list.html        # With payment buttons
```

### Payment Button Pattern
```html
<a href="{% url 'payments:paypal_payment' %}?amount=X&description=Y">
    💳 Pay
</a>
```
