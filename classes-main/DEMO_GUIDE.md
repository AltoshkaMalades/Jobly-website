## 📝 Примечания для преподавателя

### Демонстрация 1 (CI/CD)
- Показывает реальный код из `scripts/backup_and_migrate.sh`
- Создает физический файл backup_*.sql в папке backups/
- Можно открыть файл в редакторе и показать SQL содержимое

### Демонстрация 2 (Кэширование)
- Требует работающего Redis
- Если Redis недоступен, использует LocMemCache
- Заметная разница во времени: 250ms vs 5ms
- Можно использовать `redis-cli` в отдельной консоли для проверки

### Демонстрация 3 (Асинхронность)
- Требует Celery воркера в отдельном терминале
- Предпочтительно запустить оба одновременно для наглядности
- Можно показать Redis Queue при помощи `redis-cli LLEN celery`

## ✨ Что видит студент

1. **Код в файлах** - реальные функции, не мок-объекты
2. **Live консоль** - выполнение в реальном времени с логами
3. **Измерения** - конкретные числа (50x ускорение, 5ms vs 250ms)
4. **Файлы на диске** - backup_*.sql физически создается
5. **Два процесса** - браузер и воркер работают параллельно

## 🐛 Отладка проблем

### Redis не запущен
```bash
# Linux/Mac
redis-server

# Или через Docker
docker run -d -p 6379:6379 redis:alpine
```

### Celery воркер не подхватывает задачи
```bash
# Проверить, запущен ли воркер
ps aux | grep celery

# Переустартить воркер
python manage.py celery -A core worker --loglevel=debug
```

### Миграции не применяются
```bash
# Проверить статус
python manage.py showmigrations

# Применить вручную
python manage.py migrate --noinput
```
