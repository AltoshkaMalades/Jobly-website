### 🎬 ДЕМОНСТРАЦИОННЫЕ СКРИПТЫ (3 файла)

#### `demo_cicd_pipeline.py`
- **Тип:** Python скрипт (исполняемый с Django)
- **Размер:** ~300 строк
- **Название:** Демонстрация 1 - CI/CD Pipeline
- **Показывает:**
  - Создание резервной копии БД
  - Применение Django миграций
  - Полный процесс автоматизированного деплоя
- **Создает:** 
  - Папку `backups/`
  - Файл `backup_YYYY-MM-DD_HH-MM-SS.sqlite3`
- **Команда запуска:** `python demo_cicd_pipeline.py`
- **Время выполнения:** ~5 минут
- **Требуемые модули:** django, pathlib
- **Внешние зависимости:** Нет

#### `demo_caching_performance.py`
- **Тип:** Python скрипт (исполняемый с Django)
- **Размер:** ~350 строк
- **Название:** Демонстрация 2 - Кэширование и Производительность
- **Показывает:**
  - Запросы БЕЗ кэша (250ms)
  - Запросы С кэшем (5ms)
  - Разницу в производительности (50x ускорение)
- **Создает:** Нет новых файлов
- **Команда запуска:** `python demo_caching_performance.py`
- **Время выполнения:** ~5 минут
- **Требуемые модули:** django, redis (опционально)
- **Внешние зависимости:** Redis (или LocMemCache)

#### `demo_async_tasks.py`
- **Тип:** Python скрипт (исполняемый с Django)
- **Размер:** ~400 строк
- **Название:** Демонстрация 3 - Асинхронность и Celery
- **Показывает:**
  - Проблема синхронного кода (зависание на 5 сек)
  - Решение асинхронным кодом (отзывчивость <100ms)
  - Как Celery воркер выполняет задачи в фоне
- **Создает:** Нет новых файлов
- **Команда запуска:** `python demo_async_tasks.py`
- **Требуемый воркер:** `python manage.py celery -A core worker --loglevel=info`
- **Время выполнения:** ~5 минут
- **Требуемые модули:** django, celery, redis
- **Внешние зависимости:** Celery воркер (рекомендуется в отдельном терминале)
