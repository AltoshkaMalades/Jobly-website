## 📌 Описание каждого файла

### 1. `demo_runner.py` 🎛️ (ГЛАВНЫЙ МЕНЮ)

**Что это?**
- Интерактивное главное меню для запуска всех демонстраций
- Проверка требуемых модулей
- Красивый интерфейс с цветным выводом

**Как запустить?**
```bash
python demo_runner.py
```

**Что выбрать?**
```
1 - Только Шаг 1 (CI/CD) - 5 минут
2 - Только Шаг 2 (Кэширование) - 5 минут
3 - Только Шаг 3 (Асинхронность) - 5 минут
4 - Все 3 подряд - 15 минут ⭐ РЕКОМЕНДУЕТСЯ
5 - Показать руководство
0 - Выход
```

---

### 2. `demo_cicd_pipeline.py` 🚀 (ДЕМОНСТРАЦИЯ 1)

**Что это?**
- Демонстрирует автоматизированный деплой (CI/CD)
- Показывает создание резервной копии БД
- Показывает применение миграций

**Как запустить?**
```bash
python demo_cicd_pipeline.py
```

**Что видит преподаватель?**
```
✅ Код: scripts/backup_and_migrate.sh
✅ Консоль: backup_*.sql создается в папке backups/
✅ Консоль: "Migrations: 15 applied OK"
✅ Файловая система: новый файл backup_YYYY-MM-DD_HH-MM-SS.sqlite3
```

**Время выполнения:** ~5 минут

---

### 3. `demo_caching_performance.py` ⚡ (ДЕМОНСТРАЦИЯ 2)

**Что это?**
- Демонстрирует производительность кэша
- Показывает запросы БЕЗ кэша (медленно: 250ms)
- Показывает запросы С кэшем (быстро: 5ms)
- Вычисляет ускорение (50x раз!)

**Как запустить?**
```bash
python demo_caching_performance.py
```

**Что видит преподаватель?**
```
🔴 БЕЗ кэша: 250ms, 12 SQL запросов
🔴 БЕЗ кэша: 245ms, 12 SQL запросов
...

🟢 С кэшем: 245ms (первый раз - БД)
🟢 С кэшем: 5ms (из Redis!)
🟢 С кэшем: 4ms (из Redis!)
...

Ускорение: 56x раз!
```

**Время выполнения:** ~5 минут

---

### 4. `demo_async_tasks.py` 🔄 (ДЕМОНСТРАЦИЯ 3)

**Что это?**
- Демонстрирует асинхронность с Celery
- Показывает проблему синхронного кода (сайт зависает 5 сек)
- Показывает решение асинхронным кодом (сайт отзывчив <100ms)
- Показывает как Celery воркер выполняет задачу в фоне

**Как запустить?**

**Вариант A (с воркером - рекомендуется):**
```bash
# Терминал 1: Запустить Celery воркер
python manage.py celery -A core worker --loglevel=info

# Терминал 2: Запустить демонстрацию
python demo_async_tasks.py
```

**Вариант B (без воркера):**
```bash
python demo_async_tasks.py
```

**Что видит преподаватель?**

Консоль демонстрации:
```
🔴 ПРОБЛЕМА: Синхронный код
⚠️  САЙТ ЗАВИСАЕТ НА 5+ СЕКУНД!

🟢 РЕШЕНИЕ: Асинхронный код
🌐 БРАУЗЕР: ✅ Ответ за <100ms!
🔧 WORKER: Email отправляется в фоне...
🔧 WORKER: ✅ Email успешно отправлен!
```

Консоль воркера (если запущен):
```
[14:30:47] Task received: send_welcome_email_task[abc123]
[14:30:47] [Celery] Началась отправка email...
[14:30:52] [Celery] Email успешно отправлен!
[14:30:53] Task succeeded: send_welcome_email_task[abc123]
```

**Время выполнения:** ~5 минут
