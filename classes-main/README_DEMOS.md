## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

| Проблема | Решение |
|----------|---------|
| Redis не найден | `redis-server` или `docker run -d -p 6379:6379 redis:alpine` |
| Celery не работает | `python manage.py celery -A core worker --loglevel=debug` |
| Ошибка импорта | `pip install -r requirements.txt` |
| Slow консоль | Увеличьте шрифт: `Ctrl+Scroll` |
