# Jobly — Онлайн-платформа поиска работы 🚀

**Jobly** — это готовый коммерческий веб-сервис для поиска работы и подбора кандидатов. Проект разработан «под ключ»: от создания пользовательского интерфейса и базы данных до приема онлайн-платежей и настройки сервера.

🔗 **Посмотреть работающий сайт:** [https://jobly.kz](https://jobly.kz)

---

## 📸 Скриншоты и Возможности

* **Вход в 1 клик:** Авторизация через аккаунт Google без заполнения долгих форм.
* **Прием онлайн-оплат:** Интеграция с платежной системой (PayPal) для продажи подписок и услуг на сайте.
* **Высокая скорость:** Страницы загружаются мгновенно даже с мобильного телефона.
* **Безопасность:** Защита данных пользователей по протоколу HTTPS и защита от спам-ботов.
* **Аналитика для бизнеса:** Встроенный контроль продаж и отслеживание действий посетителей в реальном времени.

---

## 🛠 Технологии

* **Основной стек:** Python (Django), PostgreSQL, HTML/CSS, JavaScript
* **Инфраструктура:** Docker, Облачный сервер (Render), Автодеплой
* **Сервисы:** Google OAuth, PayPal API, PostHog Аналитика
